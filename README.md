# GST 212: Philosophy, Logic, and Human Existence — Mastery Portal

A comprehensive, offline-ready web application built to master GST 212 (Philosophy, Logic, and Human Existence) across Nigerian Universities (FUTO, UNIMAID, UNILAG, UNN, etc.).

---

## 🌟 Overview & Key Features

- **548 Verified Questions**: Extracted from all 5 course documents (`300_Gst_Questions.pdf`, `BENJAMIN. GST 212 PQ-A Exam.pdf`, `gst 212 philosophy study.pdf`, `gst212pastquestions_and_answers.pdf`, and `gst-212-lect-note.pdf`).
- **Verified Answers & Conceptual Explainers**: Every single question is verified for academic correctness and enriched with an in-depth conceptual explainer teaching the underlying theory, taxonomy, and rules.
- **Three Dedicated Study Modes**:
  1. 📖 **Study Mode**: Real-time instant feedback (Green on correct choice, Red on wrong choice with the correct answer highlighted in Orange), live Pass/Fail counters, and a highlighted Explainer drawer accessible both before and after answering.
  2. 📝 **Exam Mode**: Realistic CBT exam simulation with a Question Navigation Palette, review flagging, optional countdown timer with auto-submit, and a comprehensive post-exam results dashboard with full score breakdowns and explainers.
  3. 🗂️ **Flashcards Mode**: Interactive 3D flip cards with question on front, answer + explainer on back, and spaced-repetition mastery tracking ("Need Practice" vs. "Mastered").
- **Question Bank Repository**: Full-text searchable database with module filtering, bookmarked-only filtering, and collapsible concept explainers.
- **Minimalist Monochromatic Design**: Clean, high-contrast black/white/gray cards with crisp accent badges (zero neon gradients), complete with Dark / Light theme toggle.
- **Local Persistence**: Saves high scores, exam history, starred questions, and flashcard mastery state directly in browser `localStorage`.
